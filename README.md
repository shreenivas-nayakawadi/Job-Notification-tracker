# Job-Notification-tracker

A premium SaaS design system called "KodNest Premium Build System" - built with React, TypeScript, and Vanilla CSS.

## Features

- 🎨 Premium, calm design system
- 🧩 Reusable UI components (Button, Input, Card, Badge)
- 📐 Consistent spacing and typography
- 🚀 Built with Vite + React + TypeScript
- ✨ No gradients, no noise, just clean design

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Design Philosophy

- Calm, Intentional, Coherent, Confident
- Maximum 4 colors across entire system
- Strict spacing scale: 8px, 16px, 24px, 40px, 64px
- Serif headings, clean sans-serif body text
